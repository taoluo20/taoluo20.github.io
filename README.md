## VFX access / VFX 访问

VFX pages, categories, and direct project links share a password gate. A successful unlock is remembered in the current tab using `sessionStorage`. The password verifier is the SHA-256 digest in `app.js`.

VFX 总页、分类页和项目直达链接共用密码入口，当前标签页解锁后刷新仍然有效。密码校验值保存在 `app.js` 的 SHA-256 摘要中。

This is a browser-side gate for a static GitHub Pages site. Source data, media files, and external embeds remain public; confidential content requires server-side authentication.

这是 GitHub Pages 静态站点的前端门禁；源码数据、媒体文件及外部嵌入资源仍然公开。保密内容需要服务端鉴权。
