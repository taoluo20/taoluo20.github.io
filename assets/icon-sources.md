# Social icon sources

SVG path data retrieved from the primary Simple Icons repository on 2026-10-26.
All symbols use a `0 0 24 24` viewBox and `currentColor` fill.

- ArtStation: https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/artstation.svg
- LinkedIn: https://raw.githubusercontent.com/simple-icons/simple-icons/13.0.0/icons/linkedin.svg
- Gmail: https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/gmail.svg
- GitHub: https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/github.svg
- Instagram: https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/instagram.svg
- Simple Icons repository and license: https://github.com/simple-icons/simple-icons

Simple Icons distributes its icon set under CC0; individual marks remain their owners' trademarks.

Example embedding:

```html
<a href="https://github.com/USERNAME" aria-label="GitHub">
  <svg width="24" height="24" aria-hidden="true">
    <use href="assets/social-icons.svg#github"></use>
  </svg>
</a>
```
